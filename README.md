# منصة الرياضيات — تحضير الباك (نموذج أولي)

موقع ثابت (HTML/CSS/JS) بدون خادم. افتح `index.html` مباشرة في المتصفح.

## الميزات
- ٦١ سؤالاً على نمط الباك في ٨ وحدات (٣ ثانوي)، بثلاثة مستويات صعوبة، مع حل مفصل خطوة بخطوة وشرح سبب خطأ كل خيار
- وضع التدريب حسب الوحدة والصعوبة (تصحيح فوري)، واختبار تجريبي متوازن (١٠ أسئلة تغطي كل الوحدات، ٢٠ دقيقة)
- لوحة نتائج: إتقان كل وحدة + **علامة الباك المتوقعة** مع مجال ثقة
- تقرير للولي قابل للطباعة، مع تحليل حسب مستوى الصعوبة
- النتائج محفوظة في متصفح التلميذ (`localStorage`)

## الملفات
- `data.js` بنك الأسئلة — أضف أسئلتك هنا
- `solutions.js` الحل المفصل لكل سؤال (خطوات `s`) وسبب خطأ كل خيار خاطئ (`w`)
- `stats.js` الحسابات الإحصائية (تقدير لابلاس + مجال الثقة)
- `app.js` الواجهة والتنقل

## الخطوات القادمة
1. إضافة مواضيع الباك الرسمية للسنوات السابقة، وتمارين طويلة (مسائل) وليس فقط أسئلة اختيار من متعدد
2. حسابات للتلاميذ وخادم لحفظ النتائج (تتبع الولي عن بعد)
3. الاشتراك والدفع (بريدي موب / Chargily Pay)
