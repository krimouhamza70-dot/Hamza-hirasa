# منصة الرياضيات — تحضير الباك (نموذج أولي)

موقع ثابت (HTML/CSS/JS) بدون خادم. افتح `index.html` مباشرة في المتصفح.

## الميزات
- ٢٤ سؤالاً في ٨ وحدات من منهاج الرياضيات (٣ ثانوي) مع شرح لكل جواب
- وضع التدريب (تصحيح فوري) واختبار تجريبي (١٠ أسئلة، ٢٠ دقيقة)
- لوحة نتائج: إتقان كل وحدة + **علامة الباك المتوقعة** مع مجال ثقة
- تقرير للولي قابل للطباعة
- النتائج محفوظة في متصفح التلميذ (`localStorage`)

## الملفات
- `data.js` بنك الأسئلة — أضف أسئلتك هنا
- `stats.js` الحسابات الإحصائية (تقدير لابلاس + مجال الثقة)
- `app.js` الواجهة والتنقل

## الخطوات القادمة
1. توسيع بنك الأسئلة (مواضيع الباك السابقة) وإضافة مستويات صعوبة
2. حسابات للتلاميذ وخادم لحفظ النتائج (تتبع الولي عن بعد)
3. الاشتراك والدفع (بريدي موب / Chargily Pay)
