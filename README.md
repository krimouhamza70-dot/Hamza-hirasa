# رياضيات الباك — منصة تدريب

منصة لتحضير امتحان الباك في الرياضيات (٣ ثانوي، المنهاج الجزائري).

## الميزات
- ٦١ سؤالاً على نمط الباك في ٨ وحدات، بثلاثة مستويات صعوبة، مع حل مفصل خطوة بخطوة وشرح سبب خطأ كل خيار
- وضع التدريب حسب الوحدة والصعوبة (تصحيح فوري)، واختبار تجريبي متوازن (١٠ أسئلة تغطي كل الوحدات، ٢٠ دقيقة)
- لوحة نتائج: إتقان كل وحدة + **علامة الباك المتوقعة** مع مجال ثقة
- **حسابات**: تلميذ، ولي أمر، وأستاذ. التلميذ يجد نتائجه من أي جهاز، والولي يربط حسابه بحساب ابنه برمز من ٦ أحرف ويتابع تقريره
- **الأستاذ**: ينشئ أقساماً (لكل قسم رمز ينضم به التلاميذ)، ويرى جدولاً ملوناً لنتائج كل تلميذ في كل وحدة، ومتوسط القسم وأضعف وحداته
- **الواجبات**: الأستاذ يختار الوحدة والصعوبة وعدد الأسئلة وآخر أجل، والتلميذ يجد الواجب في صفحته الرئيسية، والأستاذ يرى من أنجزه ومن لم يبدأ
- وضع الضيف: تعمل المنصة بدون حساب (النتائج تُحفظ في المتصفح، وتُنقل إلى الحساب عند إنشائه)

## التشغيل على جهازك
يتطلب **Node.js 22.13 أو أحدث** فقط، بدون أي مكتبات إضافية.

```bash
npm start          # ثم افتح http://localhost:3000
npm test           # اختبارات الخادم
```

فتح `index.html` مباشرة (بدون الخادم) يعمل أيضاً، لكن في وضع الضيف فقط.

## الملفات
| الملف | المحتوى |
|---|---|
| `data.js` | بنك الأسئلة: أضف أسئلتك هنا |
| `solutions.js` | الحل المفصل لكل سؤال (خطوات `s`) وسبب خطأ كل خيار خاطئ (`w`) |
| `stats.js` | الحسابات الإحصائية (تقدير لابلاس + مجال الثقة) |
| `app.js` | الواجهة والتنقل والاتصال بالخادم |
| `server/server.js` | الخادم: الحسابات، الجلسات، حفظ النتائج، الربط بين الولي والتلميذ، الأقسام والواجبات |
| `test/api.test.js` | اختبارات الخادم (`npm test`) |
| `data/app.db` | قاعدة البيانات (تُنشأ تلقائياً، لا تُرفع إلى GitHub) |

## الأمان
- كلمات السر مشفرة بـ scrypt، والجلسات في كوكي `HttpOnly`
- الخادم يصحح الأجوبة بنفسه من `data.js`؛ لا يمكن إرسال نتيجة مزورة
- الولي لا يرى إلا الأبناء المرتبطين بحسابه، والأستاذ لا يرى إلا تلاميذ أقسامه
- إجابات الواجب تُقبل فقط من تلاميذ القسم، وعلى أسئلة الواجب نفسه
- حد لمحاولات الدخول (٢٠ محاولة كل ١٥ دقيقة، يُضبط بالمتغير `RATE_LIMIT`)

## النشر على الإنترنت
تحتاج استضافة تشغّل Node.js **وتحفظ الملفات بشكل دائم** (لأن قاعدة البيانات ملف). أمثلة:
- خادم افتراضي صغير (VPS) — الأرخص والأكثر مرونة
- Render أو Railway مع قرص دائم (Persistent Disk / Volume)

⚠️ الخطط المجانية بدون قرص دائم تمسح قاعدة البيانات عند كل إعادة تشغيل.

متغيرات البيئة:
| المتغير | المعنى |
|---|---|
| `PORT` | المنفذ (افتراضياً 3000) |
| `DB_PATH` | مسار قاعدة البيانات (ضعه على القرص الدائم) |
| `COOKIE_SECURE=1` | فعّله عند العمل عبر https (ضروري في الإنتاج) |
| `TRUST_PROXY=1` | فعّله إذا كان الخادم خلف وسيط (Nginx، Render...) |

**النسخ الاحتياطي:** انسخ ملف `data/app.db` بانتظام.

## الخطوات القادمة
1. إدارة الأسئلة من الواجهة (إضافة أسئلة وحلول بدون تعديل الكود)
2. التمارين الطويلة على نمط الباك (مسائل من عدة أجزاء)
3. لوحة المدير: المستخدمون، إعادة تعيين كلمات السر، إحصائيات
4. الاشتراكات والدفع (بريدي موب / Chargily Pay)
